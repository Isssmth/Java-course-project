# Institutional Permission System

A simple Spring Boot REST API for submitting and tracking institutional permission requests.

## Project structure
- `src/main/java`: Java application source
- `src/main/resources`: application configuration and resource folders
- `src/test/java`: basic Spring Boot context test
- `pom.xml`: Maven project and dependencies
- `.mvn/wrapper`: Maven wrapper configuration
- `target/`: generated by Maven when you build the project; not included in the ZIP

## Requirements
- JDK 25
- MySQL Server
- Maven installed, or a standard Maven Wrapper distribution
- Postman

## Setup
1. Extract this ZIP and open the `InstitutionalPermissionSystemComplete` folder in VS Code.
2. Run `database/create_database.sql` in MySQL Workbench.
3. Edit `src/main/resources/application.properties`; replace `YOUR_MYSQL_PASSWORD` with your MySQL password. Change username if needed.
4. Let VS Code import the Maven project and download dependencies.
5. Run `DemoApplication.java`, or open a terminal in the project folder and run `mvn spring-boot:run`.
   - This ZIP includes Maven wrapper configuration and launcher files, but not the wrapper JAR or a pre-downloaded Maven distribution. If the wrapper launcher does not work on your machine, use installed Maven (`mvn spring-boot:run`) or generate a standard wrapper with Maven.
6. Wait for the application to start on port 8080.

## Postman tests

### POST create request
`POST http://localhost:8080/permissions`

Select Body > raw > JSON:
```json
{
  "studentName": "Ismath Sulthana",
  "requestType": "Duty Leave",
  "reason": "Participating in a college hackathon",
  "requestDate": "2026-10-23"
}
```
Expected: `201 Created` and response containing the generated ID and `PENDING` status.

### GET all requests
`GET http://localhost:8080/permissions`

### GET one request
`GET http://localhost:8080/permissions/1`
Replace `1` with the ID returned by POST.

### PUT update status
`PUT http://localhost:8080/permissions/1/status`

Body > raw > JSON:
```json
{
  "status": "APPROVED"
}
```
Allowed statuses: `PENDING`, `APPROVED`, `REJECTED`.

### Verify database persistence
```sql
USE permission_db;
SHOW TABLES;
SELECT * FROM permission_request;
```

## Scope
This is a simple prototype. It supports submission, retrieval, and a basic status update, but does not enforce separate Faculty Advisor, HOD, and Principal approvals.
